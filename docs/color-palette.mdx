# Color Palette

커스텀 팔레트는 `src/app/style/globals.css`의 `@theme inline` 블록에 정의되어 있습니다.

## 사용법

```tsx
import { Text } from '@shared/ui'

<Text color="red-40">빨간색 텍스트</Text>
<Text color="gray-60">회색 텍스트</Text>
<Text color="green-40" weight="semibold">초록 semibold</Text>
```

혹은 Tailwind 유틸리티 클래스를 직접 사용:

```tsx
<div className="text-red-40 bg-gray-5 border-green-40">...</div>
```

CSS 변수 참조:

```css
color: var(--color-red-40);
background-color: var(--color-gray-5);
border-color: var(--color-green-40);
```

## TypeScript 타입

```typescript
import type { CustomColor } from '@shared/config'
// 'red-40' | 'gray-60' | ...
```

## 상수 배열

```typescript
import { CUSTOM_COLORS } from '@shared/config'
// ['gray-0', 'gray-5', ..., 'yellow-95', 'yellow-100']
```

스토리 argTypes에 활용:

```tsx
import type { Meta, StoryObj } from '@storybook/nextjs-vite'
import { CUSTOM_COLORS } from '@shared/config'

const meta = {
  argTypes: {
    color: {
      control: 'select',
      options: CUSTOM_COLORS,
    },
  },
}
```
